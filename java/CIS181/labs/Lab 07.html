CIS 161 - Lab 7

Stream a little Stream for Me.  Map, Filter, Reduce

Objectives

  • To understand and implement map, filter and reduce.
  • To gain an appreciation for the ease of streams.

Description

This lab is not going to be fun. Sorry, not sorry. It’s not bad, but it’s just not fun. Just brass-tacks code.

You are given two java files and two text files.  One java class is mostly complete as an example of using Java Streams with map, filter, and reduce.  The other is mostly empty.  As for the text files, they just contain numbers.

Exercises

1. Download this zip file Download zip file that contains the following files:

  • Streamer.java
  • Cumbersome.java
  • Numbers15.txt
  • Numbers150.txt

2. Import the code in a new lab project (Eclipse).  Make sure the .java files end up in the src folder.

3. Import the two txt files as well, making sure they are NOT in the src folder, but rather the project folder.

4. Starting with Streamer.java, you may run the code. Take time to understand it by reading the comments along with the code.

5. Toward the end of Streamer.java (~ line 109) You’ll see the comment “Your turn”.  Below that you’ll see two more comments (~ line 114 and 121) that say “Your code goes here”. 

    1. In the first case, you must replace that comment with one line of code that uses filter() AND map() to print out only even numbers of the array list.  Remember that you must convert the list to a stream first.
    2. In the second case, you must replace that comment with one line of code that uses filter() AND reduce() to get the result of multiplying all non-zero numbers in the array list together.  Remember that you must convert the list to a stream first.

6. Good? Those two lines of code are all you had to add to Streamer.java.  Next up, open Cumbersome.java

7. Cumbersome.java contains parallels to Steamer.java but with all of the steam/map/filter/reduce code commented out.  Instead, I want you to follow along with the comments to do the following (Note, the line numbers will change as you start coding):

    1. ~Line 47: Make a new array that contains all numbers in the array list, but make sure if they are negative, you convert them to positive.  You will need a loop.
    2. ~Line 54: Make a new array that contains only the negatives in the array list.  Unlike the positive array above, you will not be converting positive numbers to negative.  This “negative” array will contain less values as a result and should be sized appropriately (no wasting space).  You should count up how many negative numbers exist first (loop), create the new array from that count, then copy only the negative numbers over to the new “negative” array (loop again).
    3. ~Line 63: Sum up all the numbers of the array list into the variable sumList.
    4. ~Line 70: Same as 3, except for the positive array you made in 1.
    5. ~Line 80: Same as 3, except for the negative array you made in 2.
    6. ~Line 86: Sum up all the number on the array list, but do not include numbers that are evenly divisible by 4. Use the variable sumList yet again to generate the sum.
    7. ~Line 91: Print out only the even numbers from the array list, all on the same line, comma separated (it is okay for the last number to have a comma after it).
    8. ~Line 100: Like the way you got the sum of all the numbers in the array list, this time get the product of multiplying all the numbers in the array list together.  Use the variable product to do this.
